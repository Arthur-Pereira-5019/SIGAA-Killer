# SIGAA  Killer

**Status**: Deprecated

This project is a Python automation which automatically counts the absences you had on your current disciplines on the SIGAA platform of the IFSC colleges, since you can only count it manually, which can be a pain in the ass for people who had to not go to college for several days in different weeks, just run it and it should count the number of absences, altough you still got to wait the website latency (which normally is pretty high).

## Current Tech:
- Python with Pyautogui and Pyperclip

## Plans for the future

- Put it to work again using html scraping instead of image recognition, for more tolerance to screen differences and optimization.

# SIGAA Killer

**Status**: Depreciado

Esse projeto é uma automação de Python que automáticamente conta seu número de faltas nas disciplinas do seu curso no SIGAA da rede IFSC, tendo em vista que a outra opção seria contar manualmente, o que é uma dor de cabeça pra quem teve que faltar por muitos dias em semanas diferentes ao longo do semestre. Só rodar o código que ele vai fazer as contas, infelizmente como nós alunos do IF sabemos, a latência do site é alta, o que pode impactar na contagem.


## Tecnologia usadas:
- Python com Pyautogui e Pyperclip

## Planos Futuros

- Colocar pra funcionar de novo, só que usando scraping de HTML ao invés de reconhecimento de imagens, por aumentar a performance e a tolerância a diferenças entre telas.
